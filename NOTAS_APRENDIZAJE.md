# Bitácora de aprendizaje

Este repositorio corresponde al ejercicio guiado de GitHub Skills.
El README y los flujos del curso conservan su función original.

## Evidencia por completar

- Rama creada: pendiente de registrar.
- Commit con una modificación: pendiente de registrar.
- Pull request revisado: pendiente de registrar.
- Integración y revisión del resultado: pendiente de registrar.

Estos campos son una plantilla; no afirman que el curso esté terminado.
Añade enlaces a la evidencia cuando completes cada paso y resume qué
aprendiste. No incluyas tokens, datos privados ni credenciales.
